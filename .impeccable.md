## Design Context

### Users
Solo / small-team Turkish YouTube Shorts creators using an offline-first 0 TL stack (Gemini + Edge TTS + Pexels). They open the app to produce one publishable vertical video fast — not to configure 40 switches.

### Brand Personality
Broadcast · Decisive · Lean. Confidence over spectacle. Feels like a control desk, not a SaaS marketing page.

### Aesthetic Direction
Warm charcoal studio desk, amber signal CTA, soft bone text. Display: Syne. Body: Source Sans 3. Anti-references: purple/cyan glow dark UI, Inter/Roboto stacks, pill-stat dashboards, nested glass cards, emoji-stuffed labels.

### Design Principles
1. One job on first viewport: topic → niche → render.
2. Advanced tools collapse; never compete with the primary CTA.
3. Keep every existing control ID so the production pipeline keeps working.
4. Prefer clarity over feature theater; show status only when it changes decisions.
5. 1080p is the default publish path; test resolutions stay secondary.
